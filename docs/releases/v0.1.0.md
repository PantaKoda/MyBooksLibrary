The first Windows release of **MyBooksLibrary**: a library for your PDF books that finds each book's title, authors and table of contents, lets you search across them, and opens a chapter at its page.

## Download

**`MyBooksLibrary-0.1.0-win64.zip`**, for Windows 10 or 11 (64-bit).
- **Install:** unpack it anywhere and run `appMyBooksLibrary.exe`. There is no installer.
- **SmartScreen:** Windows may warn the first time, because the app is not code-signed yet.
- **Your library** is kept in your user data folder (`%LOCALAPPDATA%\MyBooksLibrary`), so a later version can simply replace this folder.
- **`.sha256`:** the file next to the zip lets you check the download.

## What it does

- **Import PDFs.** The library keeps its own verified copy; your original file is never changed.
- **Title, authors, edition and years** are read from the first pages, with OCR for scanned books. You can correct any field and see why a value was chosen.
- **The printed table of contents** is found and matched to the PDF's pages. Entries whose page could not be confirmed are kept and marked, never guessed. You can edit the contents.
- **Search** covers titles, authors and chapter titles. A result opens the book at its chapter's page in the built-in reader, which remembers where you stopped.
- **Collections and Trash** organize the library. Trash is reversible.
- **Save a copy with bookmarks:** a new PDF with the contents as its bookmarks. The dialog shows beforehand which entries are left out and why.
- **Back up and restore** the whole library: a verified backup folder, and restore as a new library.

## Known limits

- **Search** covers titles, authors and contents entries, not the full text of the books.
- **OCR** of scanned books is slow (several seconds per page) and uses up to about 2.5 GB of memory.
- **Windows "N" and "KN" editions** need the Media Feature Pack, or the app does not start ([PantaKoda/PDFMegine#7](https://github.com/PantaKoda/PDFMegine/issues/7)).
- **Windows only** for now: macOS and Linux need native builds of the OCR library.
- **Third-party licences** are in `NOTICE.txt` and `licenses\` in the zip.
